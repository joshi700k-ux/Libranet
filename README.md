# Libranet – Library Management System

Libranet is a Java-based Library Management System developed as an Advanced Data Structures project.

## Features

- Add and remove books
- Search books by ISBN
- Search books by title
- Register and manage library members
- Book reservation and waitlist management
- Book issue and return management
- Fine calculation for overdue books
- Genre-based book recommendations
- Most-borrowed books report
- B+ Tree index display
- Library branch network management
- Shortest-path calculation between library branches

## Data Structures and Algorithms Used

- HashMap
- LinkedList
- Queue
- Trie
- B+ Tree
- Graph
- Priority Queue
- Dynamic Programming
- Longest Common Subsequence (LCS)
- Merge Sort

## Technologies Used

- Java
- Object-Oriented Programming
- Advanced Data Structures
- Algorithms

## Project Structure

The project consists of multiple Java classes, with `Main.java` serving as the entry point of the application.

### Core Classes

- `Main.java` – Main application and menu-driven interface
- `Book.java` – Represents books in the library
- `BookCatalog.java` – Manages the book collection and search structures
- `Member.java` – Represents library members
- `MemberManager.java` – Manages registered members
- `ReservationManager.java` – Handles book reservations and waitlists
- `FineManager.java` – Handles book issues, returns, and fines
- `RecommendationEngine.java` – Generates book recommendations
- `ReportManager.java` – Generates most-borrowed book reports
- `BranchNetwork.java` – Represents the library branch network
- `ConsoleUI.java` – Handles the console interface
- `BPlusTree.java` – B+ Tree implementation for book indexing
- `BPlusTreeNode.java` – Node structure for the B+ Tree
- `Trie.java` – Trie implementation for prefix searching
- `LCSRecommendation.java` – LCS-based recommendation logic

## How to Run

1. Clone or download this repository.
2. Open the project in a Java-compatible IDE or terminal.
3. Compile all Java files.
4. Run `Main.java`.
5. Use the menu displayed in the console to interact with the system.

## Project Purpose

The project demonstrates the practical application of advanced data structures and algorithms in a real-world library management system.
